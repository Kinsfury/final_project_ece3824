# final_project_ece3824

My idea for this project is to make an electromyography (EMG) using using a raspberry pi, myoware muscle sensor kit, an OLED display, and a 5V power supply. Breadboards and connector cables are also probably required, but those aren't difficult to attain. I will buy a raspberry pi that supports external power sources, it may take it a bit but I may need everything else ordered.

The type of data to be collected will be the muscle activation. The general structure is as follows:

Muscle -> Electrodes -> EMG Module -> Analog Pin -> ADC Reading

The data will be shown as a graph of the muscle activation over a recent time (this hasn't been decided yet).
